# Тетрадь To Be

Тренажёр глагола **to be** (am / is / are) для начинающих.

- **Уровень 1:** вставить am / is / are в пропуск.
- **Уровень 2:** перевести русское предложение на английский целиком.
- Режимы: утверждение, отрицание, вопрос или всё вперемешку.
- Ошибки возвращаются через несколько заданий, трудные формы и слова попадаются чаще.
- Регистр, знаки препинания и сокращения (he's / he is / isn't) не важны.

Всё работает в одном файле `index.html` без интернета. Статистика хранится в браузере.
